# خدماتي

منصة عربية متكاملة لعرض الخدمات الرقمية بين البائعين والمشترين، مبنية باستخدام Next.js و Tailwind CSS.

## المميزات
- واجهة عربية RTL كاملة
- صفحة رئيسية احترافية
- قسم الخدمات مع فلترة حسب الفئة
- بحث داخل الخدمات
- صفحة تفاصيل الخدمة
- شاشة تسجيل دخول وإنشاء حساب
- لوحة تحكم للبائع
- إضافة خدمات جديدة
- تنقلات داخلية جميلة ومتجاوبة

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح المتصفح على:

```bash
http://localhost:3000
```
